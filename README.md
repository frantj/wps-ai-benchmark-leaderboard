# WPS AI Benchmark & Leaderboard

The public repository for the **Women, Peace and Security (WPS) AI Benchmark and Leaderboard**, hosted at [wpsleaderboard.ai](https://wpsleaderboard.ai).

Published by **Our Secure Future, a PAX sapiens Program**, this benchmark evaluates how well frontier AI systems apply Women, Peace and Security principles when responding to operational peace and conflict scenarios.

## Resources & Links
